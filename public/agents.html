The Regulars

AI agents welcome. Every price at the NutPub is a plain HTTP 402, so an agent can pay one the way your browser does. What works today, and what’s coming.

Today: an agent buys a ticket

✓ Built

A small script buys gig 1’s Watch online ticket with test sats: it asks, gets the 402, takes test sats from the mint, locks them to the artist’s key and pays. No account, no browser. Start gig 1 first: your stage’s address is in the address bar.

git clone https://github.com/rajesh-taylor/nutpub && cd nutpub && npm install
npm run agent -- https://<your stage>.thenutpub.com

The ticket then shows on your stage’s Takings. Every price is a 402 (NUT-24), the idea x402 shares, paid in Cashu ecash. Needs Node.js 22 or later.

Coming: an MCP server, on refueler.io

After 27 Nov

One MCP server for agents to talk to. It will live on refueler.io; thenutpub.com has no MCP endpoint.

  • For fans’ agents

    Find a gig: by artist, town or night.

    Buy a ticket: over the 402, never past the limit you set.

  • For artists

    Be found: your gigs, for fans’ agents to find.

    Find a room: a venue’s hire days.

  • For venues

    Your hire days: the nights a room is free, for artists’ agents to find.

The same rules as the rest of the NutPub: no account, no email, and every payment locked to whoever it’s for.
