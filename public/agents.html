Today: an agent buys a ticket

✓ Built

A small script buys gig 1’s Watch online ticket with test sats: it asks, gets the 402, takes test sats from the mint, locks them to the artist’s key and pays. No account, no browser. Start gig 1 first: your stage’s address is in the address bar.

git clone https://github.com/rajesh-taylor/nutpub && cd nutpub && npm install
npm run agent -- https://<your stage>.thenutpub.com

The ticket then shows on your stage’s Takings. Every price is a 402 (NUT-24), the idea x402 shares, paid in Cashu ecash. Needs Node.js 22 or later.
